### 3.2 橱窗ID解析

**实现位置**：`analysis_sku/analysis_sku.py` - `get_each_line_shop_window_id()`

**支持格式**：
- `支付页：3553`
- `支付：3553`
- `挽回：6187`

**解析逻辑**：
```python
def get_each_line_shop_window_id(shop_window_id_value: str, index: int, previous_shop_window_id_inner: int) -> int:
    # 1. 如果值为空，沿用上一行的橱窗ID
    if shop_window_id_value in [None, '', ' '] or pd.isna(shop_window_id_value):
        return previous_shop_window_id_inner
    
    # 2. 如果包含"支付页"或"支付"关键字，提取数字ID
    if "支付页" in shop_window_id_value or "支付" in str(shop_window_id_value):
        match = re.search(r'\d+', shop_window_id_value)
        if match:
            return int(match.group())
    
    # 3. 其他情况沿用上一行的橱窗ID
    return previous_shop_window_id_inner
```

### 3.3 商品匹配逻辑

**实现位置**：`analysis_sku/analysis_sku.py` - `analysis_sku_xls_file_new()`

**匹配策略**：
1. **优先通过商品ID匹配**：
   - 遍历所有主商品组（`shop_items`）
   - 检查每个主商品的`add_buy_info`（加购商品组）
   - 匹配所有商品类型（原价、折扣、试用、一次性等）

2. **回退到索引匹配**：
   - 如果商品ID匹配失败，使用商品序号（`product_order`）作为索引
   - 从`shop_items_list`中按索引获取商品

**关键代码**：
```python
# 优先通过商品ID匹配
if excel_product_id:
    for shop_item in shop_items_list:
        # 检查主商品的各种商品类型
        if shop_item.get("origin_item_info") and shop_item["origin_item_info"].get("id") == excel_product_id:
            current_product_info = shop_item
            break
        
        # 检查加购商品组
        if shop_item.get("add_buy_info"):
            for add_buy_group in shop_item["add_buy_info"]:
                if add_buy_group.get("origin_item_info") and add_buy_group["origin_item_info"].get("id") == excel_product_id:
                    current_product_info = add_buy_group
                    break
```

### 3.4 API请求与重试

**实现位置**：`utils/utils.py` - `_send_request_with_retry()`

**重试策略**：
- 最大重试次数：3次
- 重试延迟：1秒（首次），每次重试延迟时间翻倍（指数退避）
- 超时时间：30秒
- 重试条件：HTTP状态码为408, 429, 500, 502, 503, 504

**关键代码**：
```python
def _send_request_with_retry(url: str, headers: dict, timeout: int, max_retries: int, delay: float, backoff_factor: float) -> requests.Response:
    last_exception = None
    current_delay = delay
    
    for attempt in range(max_retries + 1):
        try:
            response = requests.get(url, headers=headers, timeout=timeout)
            if response.status_code not in RETRYABLE_STATUS_CODES:
                return response
        except requests.exceptions.RequestException as e:
            last_exception = e
        
        if attempt < max_retries:
            time.sleep(current_delay)
            current_delay *= backoff_factor
    
    raise last_exception
```

### 3.6 月均价计算

**实现位置**：`parser/shop_item_new_parser.py` - 所有价格类型解析方法

**计算公式**：
```python
# 获取主周期月数
main_cycle = get_cycle(main_period, main_period_unit)

# 获取加赠月数
give_cycle_months = get_give_cycle_months(give_cycle, give_unit)

# 计算总周期（主周期 + 加赠月数）
total_cycle = main_cycle + give_cycle_months

# 计算月均价（使用USD价格）
monthly_avg_price = price_usd / total_cycle if total_cycle > 0 else 0
```

**关键点**：
- 使用USD价格（`price_usd`或`first_exp_price_usd`）进行计算
- 必须包含加赠月数
- 如果总周期为0，月均价为0

## 四、错误处理

### 4.1 异常捕获

**实现位置**：各模块的关键函数

**处理策略**：
1. **API请求失败**：捕获`requests.exceptions.RequestException`，自动重试
2. **数据缺失**：检查`None`值，记录警告日志，跳过该行
3. **数据转换失败**：捕获`ValueError`、`TypeError`，记录警告日志，使用默认值
4. **索引越界**：捕获`IndexError`，记录错误日志，跳过该行

### 4.2 日志记录

**实现位置**：`config/logger.py`

**日志级别**：
- `DEBUG`：详细的调试信息（API请求URL、响应状态码等）
- `INFO`：一般信息（校验通过、数据提取成功等）
- `WARNING`：警告信息（商品ID匹配失败但回退成功、数据缺失等）
- `ERROR`：错误信息（校验失败、API请求失败等）

**日志格式**：
```
[2026-02-09 19:12:19,324][analysis_sku.py 73][WARNING]: =================2026-02-09 19:12:19 开始校验================
```

## 五、性能优化

### 5.1 橱窗数据缓存

**实现位置**：`analysis_sku/analysis_sku.py`

**缓存策略**：
- 使用全局字典`shop_window_id_obj_dict`缓存已请求的橱窗数据
- 如果橱窗ID已缓存，直接复用，避免重复请求

**关键代码**：
```python
shop_window_id_obj_dict = {}

# 检查缓存
if previous_shop_window_id in shop_window_id_obj_dict:
    shop_window_parser = shop_window_id_obj_dict[previous_shop_window_id]
    logger.info("复用已有的橱窗" + str(previous_shop_window_id) + "信息")
else:
    # 请求新橱窗数据并缓存
    shop_window_parser = ShopWindowParser(previous_shop_window_id, env, country, platform, is_uwp)
    shop_window_id_obj_dict[previous_shop_window_id] = shop_window_parser
```

### 5.2 请求重试优化

- 使用指数退避策略，避免频繁重试导致服务器压力过大
- 只对可重试的HTTP状态码进行重试，避免无效重试
