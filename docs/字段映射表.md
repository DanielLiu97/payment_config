# 配置文档 — pay_window 接口 — 星宿后台接口 字段映射表

> 本文档梳理 Excel 配置文档中各校验项与 pay_window API、星宿后台管理 API 三者之间的字段对应关系，便于快速定位和排查校验问题。

---

## 一、接口概览

| 接口 | URL | 用途 | 鉴权方式 |
|------|-----|------|----------|
| **pay_window** | `http://example.com/api/v1/pay_window/type/{platform}?shopwindow_id={id}&lang=zh-CN&platform={platform}&mock_country={country}` | 客户端支付页面的橱窗数据，包含所有商品槽位及其价格/周期信息 | 无（内网服务），但返回内容受用户资格限制（如首优商品需要用户满足首优条件才会出现） |
| **shop-window/listnew** | `https://example.com/shopwindow/shop-admin/manage/1/shop-window/listnew?ids={id}&...` | 星宿后台管理视角的橱窗详情，包含 `rule_config`（各槽位对应的商品ID） | Cookie（`ovsmgr_sid`） |
| **product/listnew** | `https://example.com/shopwindow/shop-admin/manage/1/product/listnew?ids={product_id}&...` | 星宿后台商品详情，包含商品名称、周期、买赠、价格等完整信息 | Cookie（`ovsmgr_sid`） |
| **price/list** | `https://example.com/shopwindow/shop-admin/manage/1/price/list?kpay_sku_ids={sku_id}` | 按 SKU ID 查询价格列表 | Cookie（`ovsmgr_sid`） |
| **price/{id}** | `https://example.com/shopwindow/shop-admin/manage/1/price/{price_id}` | 按价格ID查询价格详情（含参考展示价） | Cookie（`ovsmgr_sid`） |

### 3.2 价格类型别名归一化（`_PRICE_TYPE_ALIAS`）

| Excel 中的别名 | 归一化后的标准名称 | 说明 |
|---------------|------------------|------|
| 试用折扣价 | 折扣价-3天试用 | 后台槽位 `discount_try_item_id` |
| 直接订阅折扣价 | 折扣价 | 后台槽位 `discount_origin_item_id` |
| 加购试用 | 试用加购 | 与"试用加购"等价 |

> 文件位置：`analysis_sku/analysis_sku.py` → `_PRICE_TYPE_ALIAS` 字典

## 五、价格（H列 / F列 / G列）

### 5.1 价格ID

| 配置项 | Excel 列 / 索引 | pay_window 槽位内字段 | product/listnew 字段 | price 接口 |
|--------|-----------------|---------------------|---------------------|-----------|
| **价格ID** | H列 `price_id` / 7 | 通过 `sku_id` → `price/list` 获取 `id` | `price_id` | `price/{id}` 直接查 |

### 5.2 总价

| 配置项 | Excel 列 / 索引 | pay_window 取值 | product/listnew 取值 | price 接口取值 |
|--------|-----------------|----------------|---------------------|---------------|
| **总价(USD)** | F列 `total_price` / 5 | `{slot}.amount / 100`（分→元） | `price_amount / 100` | `price/{id}` → `price_usd / 100` |
| **参考展示价(US)** | — | 通过 `sku_id` 查 `price/list` → `other_country_prices` 中 `country=="US"` 的 `price / 100` | 同左 | `price/{id}` → `other_country_prices` 中 US 条目 |

> **注意**：`amount` / `price_amount` 的单位是**分**，需要 `/ 100` 转为美元。

### 5.3 月均价

| 配置项 | Excel 列 / 索引 | 计算公式 |
|--------|-----------------|---------|
| **月均价** | G列 `avg_price` / 6 | `price_usd / (主周期月数 + 买赠月数)` |

月均价不是接口直接返回的字段，而是由程序根据总价和周期计算得出。

**校验阈值**：`PRICE_THRESHOLD = 0.02`（允许 ±0.02 USD 的舍入误差）

## 六、商品周期（E列）

| 配置项 | Excel 列 / 索引 | pay_window 槽位内字段 | product/listnew 字段 | 单位转换 |
|--------|-----------------|---------------------|---------------------|---------|
| **主周期** | E列 `cycle` / 4 | `{slot}.period` + `{slot}.period_unit` | 订阅: `sub_cycle` + `sub_cycle_unit`（或 `rights[0]` 中取）；一次性: `one_time_cycle` + `one_time_unit` | `get_regular_time_expression_1`: Y→"年", M→"月", D→"天" |

### 周期转月数规则（`get_cycle`）

| 单位 | 月数 |
|------|------|
| Y | `period × 12` |
| M | `period` |
| Q | `period × 3` |
| D | `1`（固定按1月算，避免除0） |

### product/listnew 周期字段回退链

```
period = raw.period → raw.sub_cycle → rights[0].sub_cycle → raw.one_time_cycle → rights[0].one_time_cycle
period_unit = raw.period_unit → raw.sub_cycle_unit → rights[0].sub_cycle_unit → raw.one_time_cycle_unit → raw.one_time_unit → rights[0].one_time_cycle_unit → rights[0].one_time_unit → "Y"(默认)
```

## 七、买赠周期（J列）

| 配置项 | Excel 列 / 索引 | pay_window 槽位内字段 | product/listnew 字段 | 展示格式 |
|--------|-----------------|---------------------|---------------------|---------|
| **买赠周期** | J列 `product_give_cycle` / 9 | `{slot}.give_cycle` + `{slot}.give_unit` | 优先回退链（见下） | `"买赠" + give_cycle + get_regular_time_expression(give_unit)` → 如 `"买赠6个月"` |
| **买赠权益内容** | — | `{slot}.give_contents` | `give_contents`（如 `{"37":"6M"}`） | 校验权益与会员类型匹配 |

### product/listnew 买赠字段回退链

```
1. raw.give_cycle + raw.give_unit（优先，但很多商品这两个字段为 0/""）
2. give_right_display[0].right_duration → 正则解析 "6月"→(6,"M"), "1年"→(1,"Y")
3. raw.right_duration 或 rights[0].right_duration → 同上正则解析
```

### 买赠月数计算（`get_give_cycle_months`）

| 单位 | 月数 |
|------|------|
| Y | `give_cycle × 12` |
| M | `give_cycle` |
| Q | `give_cycle × 3` |
| D | `give_cycle / 30`（取整） |
| 空/unknown | `0` |

### 单位中文转换（`get_regular_time_expression`）

| 单位 | 中文 |
|------|------|
| Y | "年" |
| M | "个月" |
| Q | "个月" |
| D | "天" |

## 八、首优（J列）

首优信息也在 J 列（与买赠共用），格式如 `首优20%` 或 `首优10%OFF(在成交价的基础上)`，可能与买赠同时出现。

| 配置项 | Excel 位置 | 接口字段 | 处理逻辑 |
|--------|-----------|---------|---------|
| **首优折扣率** | J列，正则匹配 `首优\s*(\d+(?:\.\d+)?)\s*[%％]` | 无直接字段 | 从 J 列文本提取折扣率 n%，校验时将接口价格 × (1 - n/100) |
| **首优商品** | — | pay_window 可能不返回（需用户满足首优资格） | 通过 shop-window/listnew + product/listnew 兜底获取 |

### 首优价格计算规则

| 价格类型 | 首优计算方式 |
|---------|------------|
| **成交价 / 一次性成交价 / 折扣价** | `接口总价 × (1 - 首优折扣率)` |
| **挽回价（复合折扣）** | 在同组成交价的首优折扣基础上再叠加：`接口总价 × (1 - 成交价首优率) × (1 - 挽回首优率)` |
| **月均价** | 按首优折扣后的总价重新计算 |

### J 列预处理

校验买赠时，先调用 `_strip_first_discount_text()` 剥离首优信息，若剩余内容为空则视为无买赠。

## 十、数据获取路径与兜底机制

### 10.1 正常路径（有橱窗ID）

```
Excel K列=橱窗ID
    → pay_window API 获取橱窗数据
    → 在 shop_items[] 中按商品ID + 价格类型槽位匹配
    → ShopItemNewParser.get_*_price_new() 取价
    → sku_id → price/list + price/detail 获取 USD 价格和参考展示价
```

### 10.2 兜底路径（商品在 pay_window 中未找到）

```
pay_window 未匹配到商品
    → 2级兜底：shop-window/listnew 获取 rule_config，确认商品所在槽位
    → product/listnew 获取商品详情
    → 构建 {matched_slot: product_item} 结构
    → 正常取价流程
```

### 10.3 价格兜底（sku_id 为空或 price_usd=0）

```
取价结果 price_usd=0 或 price_id=0
    → 按 Excel H列的价格ID → price/{id} 直接查询
    → 从 matched_slot 对应的 product_item 中获取周期/买赠信息重算月均价
```

### 10.4 K列=`/`（不依赖橱窗）

```
Excel K列=/
    → product/listnew 按商品ID获取商品信息
    → 映射为 {origin_item_info: product_item}
    → get_target_info_by_condition 取价
    → 价格兜底同上
```

## 十一、完整校验项与字段来源汇总

| # | 校验项 | Excel 列 | 接口值来源 | 比较方式 | 阈值 |
|---|--------|----------|-----------|---------|------|
| 1 | 商品ID | I列 (8) | `result_dict["product_id"]` ← `{slot}.id` | 精确匹配 | — |
| 2 | 价格ID | H列 (7) | `result_dict["price_id"]` ← `price/list` 或 `price/{id}` | 精确匹配 | — |
| 3 | 商品名称 | — | `{slot}.name` / `sku_name` | 检查是否含 `%` | — |
| 4 | 三方价格名称 | — | `price/detail` → `payment_types_detail[].third_prod_val` | 检查是否含空格 | — |
| 5 | **总价** | F列 (5) | `result_dict["price_total"]` ← `{slot}.amount/100` 或 `price_usd/100` | `abs(差值) < threshold` | 0.02 |
| 6 | **月均价** | G列 (6) | `result_dict["price_avg"]` ← `price_usd / total_cycle` | `abs(差值) < threshold` | 0.02 |
| 7 | **商品周期** | E列 (4) | `result_dict["main_period"]` ← `str(period) + 单位中文` | 文本包含匹配 | — |
| 8 | **买赠周期** | J列 (9) | `result_dict["give_period"]` ← `"买赠" + give_cycle + 单位中文` | 双向文本包含 + 月数比较 | — |
| 9 | **体验价价格** | L列 (11) | `first_exp_price_usd` 或 price 接口 | `abs(差值) < threshold` | 0.01 |
| 10 | **体验价周期** | M列 (12) | `first_exp_info.duration + duration_unit` | 文本匹配 | — |
| 11 | **首优折扣** | J列 (9) | 无直接字段，程序计算 | 将接口价 × (1-折扣率) 后与 Excel 总价/月均价比较 | 0.02 |

## 十二、常见排查场景

| 场景 | 排查方向 |
|------|---------|
| "商品未在橱窗中匹配到" | pay_window 未返回该商品 → 检查 shop-window/listnew 的 `rule_config` 确认商品确实在该橱窗 |
| "get_target_info_by_condition 返回空" | 价格类型与槽位不匹配 → 检查 `_SLOTS_BY_PRICE_TYPE` 映射和 `get_target_info_by_condition` 中是否处理了该价格类型 |
| "sku_id: None 未找到价格信息" | product/listnew 返回的商品无 `sku_id` 字段 → 价格兜底用 Excel H列的 `price_id` 查询 |
| "一次性商品周期=0年" | product/listnew 中周期在 `one_time_cycle`/`one_time_unit` 而非 `sub_cycle` → 确认回退链是否覆盖 |
| "买赠周期为空但商品有买赠" | `give_cycle=0, give_unit=""` → 检查 `give_right_display[0].right_duration` 是否有值 |
| "首优商品价格不匹配" | 检查 J 列首优折扣率提取是否正确，挽回价是否需要复合折扣 |
| "月均价误差" | 检查 `total_cycle = 主周期月数 + 买赠月数` 是否正确，以及阈值是否合适 |
