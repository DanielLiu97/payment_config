# 支付配置自助校验页面 SOP（运营版）

适用对象：日常提交支付配置校验的运营同学。  
页面地址：`http://<服务机器IP>:8010/`

---

## 1. 使用前确认（1分钟）

- 服务可访问（能打开页面）。
- 准备好要校验的 Excel 数据。
- 明确本次校验参数：
  - 平台（pc/android/ios/mobile/web）
  - 环境（正式环境/测试环境）
  - 国家代码（影响配置场景，价格仍按 USD 校验）
  - 需要跑的 Sheet 编号

---

## 2. 标准操作流程

### 步骤 1：下载模板

- 点击 `下载xlsx模板`。
- 在下载的模板里填写数据（不要改表头）。

### 步骤 2：填写并启动任务

必填项（有 `*`）：
- 发起人姓名
- 平台
- 环境
- 国家代码

其余项：
- Sheet 编号（支持多个）：`1,3,5-8`
- 高级选项（可不填）：仅跑指定行（如 `30,32,44`）
- 发送 Bot 消息（默认勾选）

点击 `启动任务` 后，会生成任务 ID（如 `task-20260410-01`）。

### 步骤 3：查看结果

- 页面会自动轮询并展示进度。
- 任务结束后查看“任务摘要”：
  - 通过 / 不通过
  - 错误总数
  - 各 Sheet 结果
- 需要细看时，展开“查看原始结果(JSON)”。

---

## 3. 结果判读口径

- `通过`：本次校验未发现错误项。
- `不通过`：存在至少 1 条校验错误，请按提示修正后重提。
- 若提示 `未检测到可校验数据（有效商品ID）`：
  - 代表表中无有效数据行（常见是只有表头或商品ID列为空）。

---

## 4. 常见报错与处理

| 现象/报错 | 常见原因 | 处理方式 |
|---|---|---|
| 模板表头不匹配 | 用了旧模板或手工改了表头 | 重新下载模板并粘贴数据 |
| cookie已过期，请联系管理员更新后，再发起任务 | 服务端后台 Cookie 失效 | 联系维护人更新 `PAYMENT_ADMIN_COOKIE` 中的 `ovsmgr_sid` 并重启服务 |
| Sheet 序号格式错误 | 输入了非法格式 | 按 `1,3,5-8` 格式填写 |
| 任务秒完成且失败（无可校验数据） | 商品ID为空/无数据行 | 检查 I 列商品ID和数据内容 |
| 任务创建失败（online 环境污染） | 本机 hosts/DNS 环境被污染 | 联系维护人检查环境映射 |
| Bot 未收到消息 | 勾选项关闭或 webhook 网络波动 | 先看页面结果，再联系维护人排查 |

---

## 5. 使用规范（避免误操作）

- 同一次校验建议只对应一个业务批次，便于追踪任务 ID。
- 多个 Sheet 一次提交即可（系统会按一个任务 ID 连续执行）。
- “仅跑指定行”仅用于复核，不建议作为常规流程。
- 页面显示“通过”后再通知相关同学，不要以 Bot 是否推送作为唯一成功标准。

---

## 6. 需要谁支持

- 页面访问异常、任务无法创建、环境污染拦截：联系工具维护人（当前机器管理员）。
- 校验规则争议（字段口径、业务规则）：联系测试/产品/研发确认规则口径后再执行。
